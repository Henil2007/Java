Java Collection Framework :

Java Collection Framework (JCF) is a set of classes and interfaces that provide ready-made data structures to 
store and manipulate groups of objects efficiently.

Java provides collection interfaces like List, Set, Map, and Queue, with ready-made classes such as ArrayList, 
HashSet, HashMap, and PriorityQueue, so you don’t have to write data-handling code from scratch.

The Collection Framework improves productivity by making code more reusable, maintainable and faster to develop.


Features of Java Collection Framework :

1) Provides ready-to-use data structures (e.g., ArrayList, HashSet, HashMap).9
2) Offers interfaces (Collection, List, Set, Map, Queue) to define standard behaviors.
3) Supports dynamic resizing, unlike arrays with a fixed size.
4) Includes algorithms (sorting, searching, iteration) via the Collections utility class.
5) Improves code reusability and performance by reducing boilerplate code.



1. Core Interfaces :

The foundation of the Collections Framework is built on interfaces like Collection, List, Set, Queue, Deque and Map.
They define the behavior of different collection types and serve as a blueprint for implementations.


a) Collection Interface :

The Collection interface is the root of the Java Collections Framework, defined in the java.util package. 
It represents a group of individual objects as a single unit and provides basic operations for working with them.

Dynamic in Nature: Collections can automatically grow or shrink in size, unlike arrays that have a fixed length.

Stores Homogeneous and Heterogeneous Objects: Can hold same-type or different-type elements based on implementation.

Easy to Use: Provides convenient methods such as add(), remove(), and clear() to manage elements effortlessly.

Efficient Traversal: Allows easy access and processing of elements using loops or iterators.

Java List - Operations :

1. Adding Elements :

To add an element to the list, we can use the add() method. This method is overloaded to perform multiple 
operations based on different parameters. 

add(Object o): This method is used to add an element at the end of the List.
add(int index, Object o): This method is used to add an element at a specific index in the List

Example :

import java.util.*;

class Demo {
  
    public static void main(String args[])
    {
        List<String> al = new ArrayList<>();

        // Adding elements to object of List interface Custom elements
        al.add("Demo");
        al.add("Demo");
        al.add(1, "For");

        System.out.println(al);
    }
}

2. Updating Elements :

To update an element in a list, use the set() method with the target index and the new value. 
Since List is indexed, the element is replaced at the specified position.

Example :

import java.util.*;

class Demo {

    public static void main(String args[])
    {
        // Creating an object of List interface
        List<String> al = new ArrayList<>();

        // Adding elements to object of List class
        al.add("Geeks");
        al.add("Geeks");
        al.add(1, "Geeks");

        System.out.println("Initial ArrayList " + al);

3. Searching Elements 
Searching in a List can be done using indexOf(), lastIndexOf() methods.

indexOf(Object o): It returns the index of the first occurrence of the specified element in the list or -1 if the 
element is not found      

lastIndexOf(Object o): It returns the index of the last occurrence of the specified element in the list or -1 if 
the element is not found

Example :

import java.util.*;

class Demo {
  
    public static void main(String[] args)
    {
        // create a list of integers
        List<Integer> al = new ArrayList<>();

        al.add(1);
        al.add(2);
        al.add(3);
        al.add(2);

        // use indexOf() to find the first occurrence of an element in the list
        int i = al.indexOf(2);
      
        System.out.println("First Occurrence of 2 is at Index: "+i);

        // use lastIndexOf() to find the last occurrence of an element in the list
        int l = al.lastIndexOf(2);
      
        System.out.println("Last Occurrence of 2 is at Index: "+l);
    }
}

4. Removing Elements

To remove an element from a list, we can use the remove() method. This method is overloaded to perform multiple 
operations based on different parameters.

remove(Object o): Removes the first occurrence of the specified object from the list.
remove(int index): Removes the element at the specified index and shifts subsequent elements left.

Example :

import java.util.ArrayList;
import java.util.List;

class Demo {

    public static void main(String args[])
    {

        // Creating List class object
        List<String> al = new ArrayList<>();

        // Adding elements to the object Custom inputs
        al.add("Demo");
        al.add("Demo");

        // Adding For at 1st indexes
        al.add(1, "For");

        System.out.println("Initial ArrayList " + al);

        // Now remove element from the above list present at 1st index
        al.remove(1);

        System.out.println("After the Index Removal " + al);

        // Now remove the current object from the updated List
        al.remove("Demo");
        
        System.out.println("After the Object Removal " + al);
    }
}

b) LinkedList :

LinkedList is a class in Java Collection Framework used to store data in a node-based structure instead of a dynamic array (like ArrayList).

It is present in java.util package and implements:

List
Deque
Queue


How LinkedList Works Internally 

In ArrayList: [10][20][30][40]

In LinkedList: [10 | next] → [20 | next] → [30 | next] → [40 | next]

Each element is stored in a Node:

Data
Address of next node
Address of previous node

Java LinkedList is Doubly Linked List:

null ← [10] ⇄ [20] ⇄ [30] ⇄ [40] → null

Each node has:

previous pointer
data
next pointer


Features of LinkedList

Dynamic size
Fast insertion/deletion
No shifting of elements
Maintains insertion order
Allows duplicate values
Allows null values


When to Use LinkedList?

Use when:

Many insertions
Many deletions
Adding/removing from start or middle

Do NOT use when:
Too much searching
Frequent indexing

Vector Capacity in Java

When a Vector is created using the default constructor, it is initialized with a default capacity of 10. 

This means it can hold up to 10 elements before needing to grow in size. If the number of elements exceeds the 
current capacity, the Vector automatically increases its capacity.


Vector<String> vec = new Vector<>(); 

System.out.println("Default Capacity: " + vec.capacity()); // Output: 10


Formula to calculate new capacity :

newCapacity = oldCapacity * 2 


Example :

import java.util.Vector;

public class VectorDoublingExample {
    public static void main(String[] args) {
        Vector<Integer> vector = new Vector<>(2); // initial capacity = 2
        System.out.println("Initial capacity: " + vector.capacity());

        // Add elements to trigger capacity increase
        vector.add(10);
        vector.add(20);
        System.out.println("Capacity after adding 2 elements: " + vector.capacity());

        vector.add(30); // Triggers resize (2 → 4)
        System.out.println("Capacity after adding 3rd element: " + vector.capacity());

        vector.add(40);
        vector.add(50); // Triggers resize again (4 → 8)
        System.out.println("Capacity after adding 5 elements: " + vector.capacity());
    }
}

d) Stack :

Stack is a class in Java Collection Framework that works on the principle of:

LIFO (Last In First Out)

Meaning:

Last element added is removed first.

Example from real life:

Stack of plates
Last plate kept on top → removed first.


What is Stack?

Stack is a linear data structure where operations happen from one end only called TOP.

Push 10
Push 20
Push 30

Stack:
[10]
[20]
[30]  ← TOP

Remove element:

Pop → 30 removed first


Stack Class in Java

Stack is present in: java.util.Stack

It extends: Vector

So Stack is:

Thread-safe (because Vector is synchronized)
Slower than modern classes


Basic Stack Operations :

| Operation | Meaning            |
| --------- | ------------------ |
| push()    | Add element to top |
| pop()     | Remove top element |
| peek()    | View top element   |
| empty()   | Check if empty     |
| search()  | Find position      |

Create Stack :

import java.util.*;

Stack<Integer> s = new Stack<>();


All Important Methods in One Code :

import java.util.*;

public class StackDemo {
    public static void main(String[] args) {

        Stack<Integer> s = new Stack<>();

        // push() → Add elements
        s.push(10);
        s.push(20);
        s.push(30);
        s.push(40);

        System.out.println("Stack: " + s);

        // peek() → View top element
        System.out.println("Top element: " + s.peek());

        // pop() → Remove top element
        System.out.println("Removed: " + s.pop());
        System.out.println("After pop: " + s);

        // empty() → Check stack empty or not
        System.out.println("Is empty? " + s.empty());

        // search() → Position from top
        System.out.println("Position of 20: " + s.search(20));

        // size()
        System.out.println("Size: " + s.size());

        // contains()
        System.out.println("Contains 10? " + s.contains(10));

        // Iterate stack
        System.out.println("Elements:");
        for (int x : s) {
            System.out.println(x);
        }

        // Clear stack
        s.clear();
        System.out.println("After clear: " + s);
    }
}


Queue Interface

1. What is Queue?

A Queue is a data structure used to store elements where elements are generally processed in:

FIFO — First In, First Out


Queue declaration

public interface Queue<E> extends Collection<E>

E means the type of element.

Creating Queue

Using LinkedList : Queue<Integer> q = new LinkedList<>();

Using PriorityQueue : Queue<Integer> q = new PriorityQueue<>();

Important Queue Methods :

| Method       | Purpose              |
| ------------ | -------------------- |
| `add()`      | Add element          |
| `offer()`    | Add element          |
| `remove()`   | Remove first element |
| `poll()`     | Remove first element |
| `element()`  | View first element   |
| `peek()`     | View first element   |
| `size()`     | Number of elements   |
| `contains()` | Check element        |
| `isEmpty()`  | Check empty          |


add()
 ↓
Adds element
May throw exception if insertion fails

offer()
 ↓
Adds element
Returns false if insertion fails

remove() vs poll()

This is an important interview question.

| `remove()`              | `poll()`                |
| ----------------------- | ----------------------- |
| Removes first element   | Removes first element   |
| Returns removed element | Returns removed element |
| Empty queue → exception | Empty queue → `null`    |


| `element()`           | `peek()`              |
| --------------------- | --------------------- |
| Returns first element | Returns first element |
| Does not remove       | Does not remove       |
| Empty → exception     | Empty → `null`        |


Example :

import java.util.*;

public class QueueDemo {

    public static void main(String[] args) {

        Queue<Integer> q = new LinkedList<>();

        // Add elements
        q.add(10);
        q.add(20);
        q.add(30);

        System.out.println("Queue: " + q);

        // Offer
        q.offer(40);

        System.out.println("After offer: " + q);

        // Peek
        System.out.println("Front element: " + q.peek());

        // Element
        System.out.println("Element: " + q.element());

        // Poll
        System.out.println("Removed: " + q.poll());

        System.out.println("After poll: " + q);

        // Remove
        System.out.println("Removed: " + q.remove());

        System.out.println("After remove: " + q);

        // Size
        System.out.println("Size: " + q.size());

        // Contains
        System.out.println("Contains 30? " + q.contains(30));

        // Empty
        System.out.println("Is empty? " + q.isEmpty());
    }
}

PriorityQueue : Unlike normal Queue, PriorityQueue does not simply process elements according to insertion order.

It processes elements according to their priority.

For natural ordering of integers: Smallest number → highest priority

Creating PriorityQueue : PriorityQueue<Integer> pq = new PriorityQueue<>();


PriorityQueue Important Methods 

| Method       | Purpose                 |
| ------------ | ----------------------- |
| `add()`      | Add                     |
| `offer()`    | Add                     |
| `peek()`     | View highest priority   |
| `poll()`     | Remove highest priority |
| `remove()`   | Remove highest priority |
| `size()`     | Size                    |
| `contains()` | Search                  |
| `isEmpty()`  | Check empty             |
| `clear()`    | Remove everything       |

Deque<Integer> dq = new LinkedList<>();

Deque Important Methods

Insertion :

addFirst()
addLast()

offerFirst()
offerLast()

Removal :

removeFirst()
removeLast()

pollFirst()
pollLast()

Access :

getFirst()
getLast()

peekFirst()
peekLast()


Stack-style :

push()
pop()


Example :

import java.util.*;

public class DequeDemo {

    public static void main(String[] args) {

        Deque<Integer> dq = new ArrayDeque<>();

        // Add at first
        dq.addFirst(20);
        dq.addFirst(10);

        // Add at last
        dq.addLast(30);
        dq.addLast(40);

        System.out.println("Deque: " + dq);

        // First and last
        System.out.println("First: " + dq.peekFirst());
        System.out.println("Last: " + dq.peekLast());

        // Remove first
        System.out.println(
            "Removed first: " + dq.removeFirst()
        );

        // Remove last
        System.out.println(
            "Removed last: " + dq.removeLast()
        );

        System.out.println("Final Deque: " + dq);
    }
}


ArrayDeque

ArrayDeque is a class that implements Deque.

It uses a resizable array internally.


Important ArrayDeque Methods :

| Method          | Meaning            |
| --------------- | ------------------ |
| `addFirst()`    | Add beginning      |
| `addLast()`     | Add end            |
| `offerFirst()`  | Add beginning      |
| `offerLast()`   | Add end            |
| `removeFirst()` | Remove beginning   |
| `removeLast()`  | Remove end         |
| `pollFirst()`   | Remove beginning   |
| `pollLast()`    | Remove end         |
| `peekFirst()`   | View beginning     |
| `peekLast()`    | View end           |
| `push()`        | Add to front       |
| `pop()`         | Remove from front  |
| `size()`        | Number of elements |
| `contains()`    | Search             |
| `clear()`       | Remove all         |
| `isEmpty()`     | Check empty        |



Set Interface

Set Interface Declaration : public interface Set<E> extends Collection<E>

Creating Set : Set<Integer> s = new HashSet<>();

Set Characteristics :

No duplicate elements
No index
add()
remove()
contains()
size()
isEmpty()
clear()


| Feature         | List               | Set                       |
| --------------- | ------------------ | ------------------------- |
| Duplicate       | Allowed            | Not allowed               |
| Index           | Yes                | No                        |
| `get(index)`    | Yes                | No                        |
| Insertion order | Usually maintained | Depends on implementation |
| `add()`         | Yes                | Yes                       |
| `remove()`      | Yes                | Yes                       |


Set Hierarchy :

                 Collection
                     |
                    Set
                     |
        ┌────────────┼─────────────┐
        |            |             |
     HashSet    LinkedHashSet   SortedSet
                                    |
                                 NavigableSet
                                    |
                                 TreeSet
								 
| Class           | Duplicate | Order               |
| --------------- | --------- | ------------------- |
| `HashSet`       | No        | No guaranteed order |
| `LinkedHashSet` | No        | Insertion order     |
| `TreeSet`       | No        | Sorted order        |


Example :

import java.util.*;

public class SetExample {

    public static void main(String[] args) {

        Set<Integer> set = new HashSet<>();

        // 1. add()
        set.add(10);
        set.add(20);
        set.add(30);
        set.add(40);

        // Duplicate
        set.add(20);

        System.out.println("Set: " + set);


        // 2. size()
        System.out.println("Size: " + set.size());


        // 3. contains()
        System.out.println("Contains 30: " + set.contains(30));
        System.out.println("Contains 50: " + set.contains(50));


        // 4. isEmpty()
        System.out.println("Is Empty: " + set.isEmpty());


        // 5. remove()
        set.remove(20);

        System.out.println("After remove(20): " + set);


        // 6. addAll()
        Set<Integer> set2 = new HashSet<>();

        set2.add(30);
        set2.add(40);
        set2.add(50);
        set2.add(60);

        set.addAll(set2);

        System.out.println("After addAll(): " + set);


        // 7. containsAll()
        System.out.println(
            "Contains all set2 elements: "
            + set.containsAll(set2)
        );


        // 8. removeAll()
        Set<Integer> set3 = new HashSet<>();

        set3.add(30);
        set3.add(40);

        set.removeAll(set3);

        System.out.println("After removeAll(): " + set);


        // 9. retainAll()
        Set<Integer> set4 = new HashSet<>();

        set4.add(50);
        set4.add(60);

        set.retainAll(set4);

        System.out.println("After retainAll(): " + set);


        // 10. iterator()
        System.out.println("Using Iterator:");

        Iterator<Integer> itr = set.iterator();

        while (itr.hasNext()) {
            System.out.println(itr.next());
        }


        // 11. toArray()
        Object[] arr = set.toArray();

        System.out.println("Array elements:");

        for (Object value : arr) {
            System.out.println(value);
        }


        // 12. clear()
        set.clear();

        System.out.println("After clear(): " + set);


        // 13. isEmpty() after clear
        System.out.println("Is Empty: " + set.isEmpty());
    }
}



HashSet : HashSet is the most commonly used Set implementation.

Set<Integer> numbers = new HashSet<>();

numbers.add(50);
numbers.add(10);
numbers.add(30);
numbers.add(20);
numbers.add(10);

System.out.println(numbers);

Duplicate → Not allowed
Order → Not guaranteed
Null → One null is allowed


LinkedHashSet : LinkedHashSet maintains insertion order.

Set<Integer> numbers = new LinkedHashSet<>();

numbers.add(50);
numbers.add(10);
numbers.add(30);
numbers.add(20);
numbers.add(10);

System.out.println(numbers);

The duplicate 10 is removed, but the original insertion order remains.

Duplicate → Not allowed
Order → Insertion order
Null → One null is allowed


TreeSet : TreeSet automatically sorts elements.

Set<Integer> numbers = new TreeSet<>();

numbers.add(50);
numbers.add(10);
numbers.add(30);
numbers.add(20);
numbers.add(10);

System.out.println(numbers);

Duplicate → Not allowed
Order → Sorted order
Null → Generally not allowed


TreeSet Has Extra Methods

Because TreeSet implements NavigableSet, it provides additional useful methods.

import java.util.*;

public class TreeSetExample {

    public static void main(String[] args) {

        TreeSet<Integer> numbers = new TreeSet<>();

        numbers.add(10);
        numbers.add(20);
        numbers.add(30);
        numbers.add(40);
        numbers.add(50);

        System.out.println(numbers);

        System.out.println("First: " + numbers.first());

        System.out.println("Last: " + numbers.last());

        System.out.println("Lower than 30: "
                + numbers.lower(30));

        System.out.println("Higher than 30: "
                + numbers.higher(30));

        System.out.println("Floor of 35: "
                + numbers.floor(35));

        System.out.println("Ceiling of 35: "
                + numbers.ceiling(35));

        System.out.println("Descending: "
                + numbers.descendingSet());

        System.out.println("HeadSet: "
                + numbers.headSet(30));

        System.out.println("TailSet: "
                + numbers.tailSet(30));

        System.out.println("SubSet: "
                + numbers.subSet(20, 50));
    }
}


Output :

[10, 20, 30, 40, 50]

Last: 50

Lower than 30: 20
Higher than 30: 40

Floor of 35: 30
Ceiling of 35: 40

Descending: [50, 40, 30, 20, 10]

HeadSet: [10, 20]

TailSet: [30, 40, 50]

SubSet: [20, 30, 40]
